# GeoTagr – Geo-Tag Camera Android Application

## Overview

GeoTagr is an Android application developed during an internship at DCT’s Dhempe College of Arts & Science. The application combines camera functionality with location services to capture photographs with geographic information.

The project provided practical experience in Android application development, camera integration, location-based functionality, and application maintenance.

## Features

- **Photo Capture:** Capture photographs using the device camera.
- **Location Integration:** Retrieve GPS coordinates and location information.
- **Geo-Tagging:** Associate geographic information with captured photographs.
- **Photo Gallery:** Preview, select, share, and delete photographs.
- **Authentication:** Administrator-restricted sign-up and authentication functionality.
- **User Data Management:** Firebase integration for relevant user information.

## Technologies Used

Kotlin, Android Studio, Android SDK, CameraX, Firebase Authentication, Firebase Realtime Database, XML.

## Download and Installation

The compiled Android application is available in the [GitHub Releases](../../releases) section.

1. Open the latest available release.
2. Download the APK asset.
3. Transfer the file to a compatible Android device if necessary.
4. Open the APK and follow the installation prompts.
5. Grant the required camera and location permissions when prompted.

**Access Note:** The application has an administrator-restricted sign-up process. Downloading the APK does not guarantee access to the application's authenticated features. Access depends on the configured authentication system and backend services.

**Security Note:** Install APK files only from sources you trust.

## Repository Contents

This repository provides the compiled APK for demonstration and evaluation. The APK is a distributable application package and does not provide the original editable Android Studio source project.

## Privacy and Security

- No administrator credentials or private user information are intentionally published in this repository.
